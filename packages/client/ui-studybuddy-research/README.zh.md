# StudyBuddy 研究工作台

[English](README.md) | 中文

桌面页面把原 K-Dense 工作台与 Harness 的 `conversation.content` 嵌入模式组合。原文件树、编辑器及科学文件预览保留在本机网页中。每个研究项目分别持有原生会话引用；原生对话子树常驻 `shell.overlay`，左栏切换后的主面板只提供显示位置。普通会话继续保留各自的引用和草稿。

页面沿用空闲预加载队列。Main 管理原账号代次、项目目录、本机服务和私有原生操作。网页仅获得打开项目、引用、草稿与模型控件意图，这些意图不提交模型请求；已有原生草稿会保留。切换账号时先撤下显示目标，再释放会话引用、销毁网页分区。

右侧空闲栏显示客观的九章图文指南，提供章节目录和半透明的上一页、下一页按钮；已登录账号的本机网页准备期间也可显示指南。真实界面局部截图与功能示意图分别标注；紧凑的编号放在标注对象下方，点击查看简短说明，点击图片用弹窗放大。图片底边的编号在图外预留位置。图片按章节加载为独立资源块，不进入客户端启动首包。原始 PNG 位于 `src/client/guide-images/`；替换图片后运行 `node scripts/generate-guide-image-modules.mjs` 重新生成编码模块。普通页面与项目切换保留阅读位置，切换账号后重置；指南隐藏时撤下目录和放大弹窗。打开项目后恢复常驻的原生对话。阅读指南不会提交模型或服务请求。嵌入模式的项目首页保留文字标题，去掉重复品牌图片。

资源 pin 标识已经校验的候选。CLI 专家、原始工作流的高级控制和真实 OpenRouter Fusion 仍属于独立的兼容工作；本包不证明全部研究流程已经兼容或付费服务已经验收。进展见[执行记录](../../../../output/studybuddy-k-dense-integration-2026-10-13/implementation/progress.md)。
