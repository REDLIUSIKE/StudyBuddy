# StudyBuddy 视频工作区

[English](README.md) | 中文

编辑器顶部最右侧的“退出”会先等待编辑写入，随后停止当前项目的活动、释放原生对话视图并返回项目列表，不自动重开。切换板块仍保留编辑器。已移除版本历史界面、自动读取和专用事件监听；时间线撤销/重做与项目文件继续保留。

此桌面插件将原版 OpenFilm Studio 编辑器与现有 Harness 原生 Conversation 组合。每个准入项目保留独立 Session 和草稿。Main 管理账号范围、项目准入、本地进程、私有通信和图像引用。选择片段、区域或画面会向当前草稿追加引用，不会自动提交。

当前项目的原生 Conversation 接入现有右侧文件预览面板，导出视频链接和附件卡片在对应项目的 Session 下打开，不改变普通聊天选择。可见编辑器的顶层页面可以进入 HTML 全屏；生成影片的子框架、隐藏编辑器和已撤销的账号代次不能申请全屏。

编辑器运行在隔离网页中，预加载仅供顶层页面使用。生成影片使用独立来源，没有原生 API。Main 只接收当前项目媒体接口提供的帧图，限制大小并统一转为 PNG；预览项目或播放时间变化时会丢弃捕获结果。原有时间线布局和操作保留在 OpenFilm 中。

视频领域以独立 Harness 配置运行，使用限定范围的工具。模型、凭据、请求身份和计费由现有原生媒体目录及执行能力管理。已删除服务商和自定义服务设置；模型页读取当前账号及项目的原生目录，对话模型仍在 Conversation 中选择。编辑器默认使用 StudyBuddy 浅色主题，保留原有面板布局，内置可离线打开的编辑示例。不运行独立 Agent 守护进程，也不打包第二套 Electron 或 Node。

原生模型缺少视频配音或转写要求的逐字时间戳时，不会获得视频选择权限；这不影响同一原生目录中其他已经支持的模型。目录请求失败或原生身份无效时仍拒绝放行。

打开原生模型菜单时，编辑器网页继续显示并保留项目状态；菜单位于前台时，网页暂停接收鼠标和键盘输入。模态对话框仍会隐藏网页，撤销账号范围后会移除网页。

此集成仍在开发。原生路径选择、项目取消、带时间戳的转写与翻译、持久化配音音效结果和原生 Session ZIP 导出已有相关测试覆盖。正式资源仍须等待当前目录覆盖与原账号完整流程验收。用户已排除音乐生成和在线素材源，本地素材导入与编辑继续保留。源码测试和供应商记录回放不代表真实原生网关、钱包或完整界面验收。见[已确认计划](../../../../docs/superpowers/plans/2026-10-17-openfilm-video.md)，执行记录位于 `.superpowers/sdd/2026-10-17-openfilm-video/`。
