# @deepseek-ai/dsh-client-ui-studybuddy-support

[English](README.md) | 中文

## Use this package

插件在现有设置项之后增加“帮助与反馈”，不增加主导航入口，不替换 Harness 的会话持久化、崩溃报告或上游反馈。已登录的桌面主进程提供支持接口；其他环境明确显示暂不可用。

页面可以预览并上传诊断日志，提交带可选截图的问题，复制已确认的 LOG/ISSUE 编号，并复用产品更新检查。同一账号关闭设置后保留草稿和操作；归属失效时清空。结果未确认的问题不会自动重复提交。完整 API Key 附件保留原策略，提交前明确说明；不会自动采集整段聊天或登录凭据。

同一插件在“帮助与反馈”之后提供“关于 StudyBuddy”。页面分两栏列出主要集成项目与设计参考，仅显示项目链接与许可证，不显示框架和逐项目介绍。共创入口展示可复制的 QQ 群 120796873，不展示个人 QQ 号。GitHub 开源计划按未来发布描述，不虚构仓库地址或日期；页面不依赖支持接口或登录会话。

## Model Experience

本功能不向模型发送提示词，不改变模型选择、路由、用量或价格事实。日志包校验、截图限制、持久日志上传尝试和服务端可用状态仍由原支持服务负责。

## Known limitations

采集来源状态只说明已观察到的诊断，不代表工具已安装或已连接。尚未接入采集的来源保持不可用。关闭页面后远端对象仍可能完成，关闭不等于删除。问题提交结果未确认时，本次账号生命周期内禁止新上传，保留已确认的 LOG 编号用于查询。支持请求超时只拒绝该请求，不结束其他原生任务；迟到的回执仍按原请求关联。

## Implementation

[已确认设计](../../../docs/superpowers/specs/2026-10-12-harness-help-feedback-design.zh.md)定义采集及归属规则。无 React 依赖的控制器映射结果；声明式存储只保存界面草稿。客户端入口只导出 Cordis 加载所需的值。
